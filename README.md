## 🚀 Featured Project

### 🧾 Automated Invoice Creation System

An end-to-end invoice automation system built with n8n.

The workflow automatically:

- Retrieves invoice-ready data from Google Sheets
- Validates customer and invoice information
- Calculates invoice totals and discounts
- Generates invoice documents
- Converts invoices to PDF
- Stores invoices in Google Drive
- Creates Gmail drafts with invoice attachments
- Updates invoice statuses
- Logs workflow executions
- Handles failed records

**Technologies:** n8n · JavaScript · Google Sheets · Google Drive · Google Docs · Gmail · REST APIs
